# Chapter 05–06 공통 실습 데이터

- [원본 출처·해시](raw/README.md): 강사 Chapter05 전용 오류 포함 샘플 4종.
- `raw/`: 원본 보존. 전처리로 덮어쓰지 않음.
- `processed/`: Chapter05에서 생성한 clean CSV 4종. Chapter06이 그대로 읽음.
- `quarantine/`: 일반 판매 분석에서 분리한 원래 행과 행별 사유. 실제 오류 확정과 다름.

일부 날짜 실패는 NaT로 보존하고, 미래 날짜와 큰 값은 후보 플래그로 표시했다.
`line_total`은 상세 한 행의 수량×단가다. 전체 합을 곧바로 매출/순매출로 해석하지 않는다.

실제 고객 자료나 비공개 자료가 아닌 수업용 합성 데이터다.
