# Chapter 08. 작은 데이터 분석 프로젝트 완성하기

주 제출물은 [실행 결과를 저장한 Notebook](chapter08.ipynb)이다. 별도의 χ-separation 뇌지도 프로젝트와 구분되는 쇼핑몰 합성 데이터 종합 실습이다.

원본 CSV4개부터 임시 폴더에서 다시 전처리했다. 원본152/102/302/765행은 clean150/96/298/724행으로 재생성되었고 기존 clean4개와 해시가 같았다. 기존 raw/clean8개는 수정하지 않았다. 원본 행 감소와 격리 사유, PK/FK·병합·계산식 검증을 표로 남겼다.

초기 completed 전체430상세·137,335,000원에서는 날짜 결측6상세·1,903,000원이 월별 집계에 빠져 FAIL이었다. 기준일2026-10-08 이후3상세·909,000원도 별도 영향으로 기록했다. 모든 금액 집계에 공통으로 completed·유효 주문일·기준일 이하 조건을 적용한 최종 범위는421상세·175상세 보유 주문·96고객·134,523,000원이다. 조건 충족176주문 중 상세가 없는1주문은 평균 분모에서 제외했다. 날짜를 추정하여 복원한 것은 아니다.

원본을 별도로 읽은 Decimal 재집계와 카테고리·월·고객 합계가 같다. 이 검산은 전처리 격리 행 번호를 공유한다는 범위를 명시했다. 일부 상세가 격리된18주문을 모두 제외하면157주문·120,972,000원이므로 원래 청구총액이나 순매출·이익으로 해석하지 않는다.
