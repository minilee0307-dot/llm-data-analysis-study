# Chapter 07. 그래프로 데이터의 이야기를 보여주기

주 제출물: [실행 결과가 저장된 Notebook](chapter07.ipynb)

2025-07-02~2026-08-28의 completed·유효 주문일·고정 기준일 2026-10-08 이하인 상세 421행, 금액이 있는 주문 175건을 사용했다. `quantity × unit_price` 합은 **134,523,000원**이며 카테고리·월·상품·고객 합계가 같다. 금액 1위는 패션 32,940,000원(24.49%)이다. 날짜·상태 조건을 통과한 176건 중 상세가 없는 주문 1건은 평균의 분모에서 제외했다.

일부 상세가 격리된 주문 18건이 기본 결과에 남아 있어 금액은 원래 청구총액이 아닌 남은 유효 상세 합계다. 이 주문을 모두 제외하면 157주문·120,972,000원이다. 입력 raw/clean CSV 8개는 수정하지 않았고 해시를 대조했다.

대표 막대·선·가격 히스토그램 외에 공식 산점도·익명 고객 Top10 가로 막대·전체 주문 상태 막대와 bins=10/20/30 비교까지 수행했다. 상품 가격 분포는 전체 96개와 200,000원 이하 확대 95개를 나란히 표시했다. 9,999,999원 후보 1개는 삭제하지 않았다. 월별 달력 14개월의 누락 월과 실제 0원은 모두 0개이며 경계 월 수집 완전성은 확인되지 않았다.

[images](images/)의 PNG 7개는 실제 집계표로 만든 그래프다. Notebook 표와 inline 그래프가 핵심 Evidence이고, 외부 UI 화면을 모방한 이미지가 아니다. [LLM 검토 기록](llm_review.md)의 제안은 실제 artist 대조와 사용·수정·보류 판단을 거쳤다. 작성·실행·검토에는 Codex의 도움을 받았다.

기존 수업 가상환경 Python 3.14.3, pandas 3.0.5, NumPy 2.5.3, matplotlib 3.11.1을 사용했다. 한글 폰트는 실제 파일이 있는 AppleGothic을 사용했고 다른 환경에서는 설치된 한글 폰트를 선택하도록 했다. 저장소 루트에서 다음을 실행한다.

```text
python scripts/run_visualization.py
```
