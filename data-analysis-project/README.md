# 데이터분석 프로젝트 — χ-separation atlas 분석

공개 MRI 뇌지도의 영역별 성분 차이와 ROI 경계 선택의 영향을 분석한다. 현재 단계는 **1차 기획 및 실제 데이터 확보·구조 검사**이며, 본 분석과 최종 보고서는 후속 단계에서 진행한다.

- 제출 파일: [01_proposal.md](01_proposal/01_proposal.md)
- 확보·검사 설명: [data-check.md](docs/data-check.md)
- 실제 실행·원본 출처·해시: [data-check.json](docs/data-check.json)
- AI 활용: [ai-use-log.md](docs/ai-use-log.md)
- 직접 작성한 검사 코드: [check_atlas.py](scripts/check_atlas.py)
- 환경: [requirements.txt](requirements.txt)

공식 원자료는 [SNU-LIST/chi-separation-atlas](https://github.com/SNU-LIST/chi-separation-atlas)에서 내려받는다. 이용조건에 따라 원자료·변형 뇌지도는 재배포하지 않으며 로컬 `data/raw/`는 Git에서 제외한다. 공개 저장소에는 기획·검사 기록과 직접 작성한 코드만 담는다. 챕터 실습과 이 자유 주제 프로젝트는 별개 제출물이다.
