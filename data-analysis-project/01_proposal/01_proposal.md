# 공개 χ-separation 뇌지도의 영역별 특성과 영역 선택에 따른 측정값 변화 분석

데이터분석 프로젝트 1차 과제 — 프로젝트 기획 · 작성일: 2026-10-08

## 1. 프로젝트 제목

**공개 χ-separation 뇌지도의 영역별 특성과 영역 선택에 따른 측정값 변화 분석**

공개된 MRI 뇌지도와 영역별 통계표를 이용해 자기감수성 성분의 차이를 비교하고, 관심 영역의 경계를 줄였을 때 측정값이 얼마나 변하는지 분석한다. 원래 MRI 신호에서 지도를 재구성하는 작업은 포함하지 않는다.

## 2. 프로젝트 배경 및 목적

심리학과 전기·신호처리에 대한 관심을 MRI 정량 분석 학습으로 연결하고자 한다. MRI 영상을 보는 것에서 한 걸음 나아가, 뇌의 특정 영역에서 계산한 숫자가 무엇을 뜻하고 분석자의 영역 선택에 얼마나 영향을 받는지 알아보는 것이 목적이다.

일반적인 정량적 자기감수성 지도(QSM)는 여러 자기감수성 원천의 합성된 특성을 보여준다. χ-separation은 상자성 성분(χpara)과 반자성 성분(χdia)을 분리해 살펴보는 방법이다. 이 성분들은 철·미엘린과 관련된 조직 특성을 연구하는 데 쓰이지만, 각각의 값을 철 함량·미엘린 함량이나 질병 진단으로 곧바로 해석할 수는 없다. 본 프로젝트에서는 **공개 뇌지도에 나타난 성분별 분포와 측정의 민감도**로 해석 범위를 제한한다. 배경은 [χ-separation atlas 원 논문](https://doi.org/10.1002/nbm.5226)과 [자기감수성 원천 분리 리뷰](https://doi.org/10.2463/mrms.rev.2024-0001)를 참고한다.

결과는 MRI 입문자가 뇌 영역별 수치의 차이를 이해하고, 후속 연구에서 관심 영역(ROI: region of interest)을 정할 때 경계 선택의 영향을 점검하는 예제로 활용할 수 있다. LIST의 공개 데이터 구조를 이해하고 재현 가능한 분석을 수행하는 경험도 얻고자 한다.

## 3. 핵심 분석 질문

| 질문 | 사용할 데이터와 분석 단위 | 답을 제시할 방법 |
| --- | --- | --- |
| **Q1. 뇌 영역별 χpara와 반자성 성분의 크기 \|χdia\|는 어떤 차이가 있는가? 두 성분에서 상대적으로 높은 영역은 같은가?** | 두 ROI 통계 CSV의 `ROI_name`, `Mean`, `SD`. 영상 라벨과 대응되는 24개 영역을 주 비교 대상으로 사용 | 성분별 평균·순위, 순위 차이, 산점도와 영역별 비교표. 추가 종합 영역 2개는 별도 표시 |
| **Q2. 평균 QSM 값이 비슷한 영역도 분리된 χpara·\|χdia\| 프로파일은 다르게 나타나는가?** | 동일한 24개 ROI에서 `chi`, `chi_para`, `chi_dia` 영상의 평균을 각각 계산 | 전체 영역의 QSM–성분 관계를 그린 뒤 QSM 평균 차이가 가장 작은 영역 쌍 3개를 기술적으로 비교. 실제 차이가 작으면 그 사실도 보고 |
| **Q3. ROI의 바깥 경계를 한 단계 제외하면 영역별 평균과 순위는 얼마나 변하는가? 어떤 영역이 더 민감한가?** | 원본 ROI와 경계 축소 ROI에서 추출한 세 지도 값 | 축소 전후 평균 차이(ppb), 순위 변화, 남은 복셀 수·비율을 함께 비교 |

Q2의 쌍 선택은 분리 성분의 결과를 보기 전에 **QSM 평균 차이만으로** 정한다. 이는 비슷한 QSM의 구체적 예를 찾는 기술적 비교이며, 통계적 유의성이나 임상적 차이를 뜻하지 않는다. Q3의 경계 축소 역시 실제 정답 ROI를 찾는 과정이 아니라, 정해진 조작에 대한 민감도 실험이다.

## 5. 예상 데이터 구조

아래 원본 구조는 다운로드한 파일에서 확인했으며, 분석용 표는 이후 생성할 계획이다.

| 원본 파일 | 실제 변수·형태 | 역할 |
| --- | --- | --- |
| `chi_para_ROI_stats.csv` | `ROI_name` 문자열, `Mean`·`SD` 실수 | 상자성 성분의 공개 ROI 통계, ppb |
| `chi_dia_ROI_stats.csv` | `ROI_name` 문자열, `Mean`·`SD` 실수 | 반자성 성분의 공개 ROI 통계, ppb |
| `label_names.csv` | `Index` 정수, `ROI_name` 문자열 | 영상 라벨 번호와 영역명 대응 |
| `NIfTI/labels.nii.gz` | `uint16` 3차원 배열, 배경 0·영역 1–24 | ROI 마스크 |
| `NIfTI/chi.nii.gz` | `float64` 3차원 배열 | QSM 지도, ppm |
| `NIfTI/chi_para.nii.gz` | `float64` 3차원 배열 | 상자성 성분 지도, ppm |
| `NIfTI/chi_dia.nii.gz` | `float64` 3차원 배열 | 반자성 성분의 절댓값 지도, ppm |

원본에는 환자별 행, 질병 결과, 개인별 연령·성별 컬럼이 없다. 공식 설명상 106명 건강한 뇌에서 유래한 집단 뇌지도이지만, **여기서 확보한 24개 ROI를 106명 개인 표본처럼 취급하지 않는다.** 연령 효과·질병 예측·개인 간 차이에 대한 분석은 수행 범위에서 제외한다.

분석용 긴 형식 표는 `roi_id`, `roi_name`, `map_type`, `mask_version`, `n_voxels`, `retained_fraction`, `mean_ppb`, `median_ppb`, `voxel_sd_ppb`로 구성한다. 기본적으로 **24개 영역×3개 지도×2개 마스크 조건=144행**이며, 축소 후 빈 ROI는 복셀 수 0과 결측 요약값으로 명시한다. 영상 내 복셀의 산포인 `voxel_sd_ppb`와 공개 통계표의 `SD`를 서로 같은 지표라고 가정하지 않는다.

## 6. 예상 분석 방법

1. **구조·품질 확인과 전처리**: 원본을 보존하고 파일 해시, 결측·중복, ROI 연결, 영상 크기·affine을 검사한다. 원본 이름과 연결용 이름을 분리한다. 단위는 ppb로 통일하고 χdia의 원부호와 절댓값 변수를 구분한다. 이 단계의 기본 검사는 이미 실행했으며, 분포·이상값 검토는 다음 단계에서 진행한다.
2. **Q1의 기술통계·EDA**: 공개 통계표의 평균·SD를 그대로 구분해 표시하고 성분별 순위와 산점도를 만든다. SD를 임의로 표준오차·신뢰구간으로 바꾸지 않는다. 두 종합 영역은 하위 영역과 겹칠 수 있으므로 24개 영역의 독립된 추가 표본으로 넣지 않는다.
3. **Q2의 ROI 집계**: `nibabel`로 읽은 지도에서 동일한 ROI 마스크를 적용해 평균을 구한다. QSM과 분리 성분을 같은 축척으로 비교하고, QSM 평균이 가까운 영역 쌍의 성분 차이를 표로 보여준다. 지도 평균과 공개 CSV 평균은 생성·평균화 과정이 다를 수 있으므로 정확한 일치를 강제하지 않는다. 불일치가 있으면 단위·부호·영역 대응부터 점검한다.
4. **Q3의 경계 민감도**: 각 ROI에 대해 상하·좌우·앞뒤 **6방향 이웃이 모두 같은 ROI에 속하는 복셀만 남기는 1회 침식**을 적용한다. 원본과 축소본의 평균 차이 `축소 평균−원본 평균`, 절대 차이, 순위 변화를 계산한다. 각 결과에 남은 복셀 수와 비율을 붙이며, 사라진 ROI는 0으로 대체하지 않는다. 0 근처 평균에서 과장될 수 있는 백분율 변화 대신 ppb 차이를 우선 사용한다.
5. **검증과 해석**: 복셀 수의 감소, 원본 보존, 단위 변환, ROI별 직접 계산을 점검한다. 대표 영역을 따로 추출해 집계 코드를 대조하고, 몇 개의 단면에서 원본·축소 마스크를 겹쳐 시각적으로 검사한다. 큰 변화가 관찰돼도 곧바로 생물학적 차이나 측정 오류의 증거라고 해석하지 않는다.

예상 시각화는 ① 영역별 성분 평균·SD 그림, ② χpara–\|χdia\| 산점도와 순위표, ③ QSM이 비슷한 영역 쌍의 성분 비교, ④ 경계 축소 전후 차이와 복셀 유지율 그림, ⑤ 대표 MRI 단면의 마스크 겹침 그림이다. 수치 결과마다 관찰 사실과 해석을 분리해 적는다.

Python 입문 단계에서 수행 가능하도록 `pandas`, `NumPy`, `nibabel`, `matplotlib`을 중심으로 구현한다. 이 질문에는 예측 모델보다 기술통계와 조건을 바꾼 재계산이 적절하므로 머신러닝을 필수로 두지 않는다. 기본 범위는 24개 ROI와 1회 경계 축소이며, 2회 축소 비교는 일정이 허용될 때만 확장한다.

## 7. 생성형 AI 활용 계획

생성형 AI는 질문을 데이터 변수로 구체화하고, CSV 연결·영상 읽기·집계·시각화 코드 초안을 작성하며, 오류 해결과 보고서 표현을 검토하는 데 활용한다. AI의 조직·의학적 해석은 논문 근거 없이 결론으로 채택하지 않는다.

이번 기획 단계에서는 Codex를 이용해 공식 공개 자료를 탐색하고 검사 코드를 작성·실행했다. 실제 출력에서 **26행 통계표와 24개 라벨의 차이, χdia의 부호 표현, ppm·ppb 변환 필요성**을 확인해 기획에 반영했다. 이를 작성자가 모든 코드를 수동으로 검토했거나 본 분석을 완료한 것으로 기록하지 않는다.

후속 분석에서는 AI가 제안한 코드와 해석을 다음과 같이 검증할 계획이다.

| AI 활용 | 채택 전 확인 | 남길 기록 |
| --- | --- | --- |
| 컬럼 연결·단위 변환 코드 | 실제 컬럼과 원본 몇 행 대조, 1 ppm=1,000 ppb 변환 확인 | 실행 출력과 처리 전후 표 |
| ROI 집계·경계 축소 코드 | 대표 ROI 직접 추출, 복셀 수 감소와 단면 마스크 확인 | 계산 비교와 마스크 그림 |
| 시각화·결과 해석 | 그래프와 집계표 대조, 단위·표본 수준·문헌 근거 확인 | 채택·수정·보류 이유 |

Prompt Log에는 실제 요청, AI 제안, 실행으로 확인된 사실, 아직 검증하지 않은 해석을 구분한다. 현재까지의 실제 사용은 [AI 활용 기록](../docs/ai-use-log.md)에 정리했다.

## 8. 향후 진행 계획

아래 날짜는 개인 작업 목표이며, 후속 과제의 공식 마감은 LMS 공지에 맞춰 조정한다.

| 단계 | 개인 목표 | 완료 기준과 산출물 |
| --- | --- | --- |
| 1차 기획 | 10월 8–9일 | 질문 3개, 실제 확보 가능성, 데이터 구조·이용조건, 학기 범위를 담은 본 기획안 |
| 데이터·EDA | 10월 중·하순 | 단위·부호·ROI 연결 검증을 설명할 수 있는 Notebook, 24개 영역 EDA 및 품질 보고 |
| 본 분석·검증 | 11월 | 세 지도 ROI 집계, 1회 경계 축소 실험, 빈 ROI·유지율 처리, 대표 계산·단면 검증 |
| 최종 정리 | 12월 | 재실행 가능한 Notebook·환경 목록, 질문별 결과표와 그림, 해석·한계·AI 활용 기록을 포함한 최종 보고서 |

우선 배울 내용은 ROI·복셀·affine의 의미, NIfTI 읽기, 배열 마스킹, 평균·순위·단위 변환, 경계 축소의 원리이다. MRI 획득 물리 전체나 딥러닝 학습을 먼저 마쳐야 하는 구성은 피하고, 실제 분석에 필요한 개념을 순서대로 학습한다.

최종 핵심 산출물은 **분석 Notebook, 검증 기록, 질문 3개에 답하는 보고서**이다. Streamlit은 기본 분석과 검증을 마친 뒤 여유가 있을 경우 결과를 전달하는 선택 항목으로 둔다. NIfTI 분석의 난도가 예상보다 높으면 먼저 확보한 CSV의 Q1을 완성하고, Q2·Q3은 대표 ROI에서 검증한 뒤 24개로 확장한다. 집단 뇌지도만으로 개인·질병 수준 결론을 내릴 수 없다는 한계는 최종 보고서에도 유지한다.
